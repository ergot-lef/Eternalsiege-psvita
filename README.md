# Eternal Siege — PS Vita edition

*[Version française](README.fr.md)*

A native PS Vita (homebrew) version of **Eternal Siege**: defend a medieval castle in first person against waves of attackers that advance through history, from the Middle Ages to drone swarms.

The Vita cannot host the PC game's persistent 32-player server, so this version focuses on a **living, destructible world** rather than heavy graphics.

## Features

- **Stone-block castle**: walls crack, lose stones and collapse in whole sections. Rubble forms slopes enemies can climb. Hold ○ to repair.
- **Deformable terrain**: shell and cannonball craters.
- **Persistent blood**: splatters, pools spreading under bodies, limbs torn off by explosions. Rain slowly washes the battlefield.
- **Fire**: flaming arrows (draw your bow next to a brazier), boiling oil above the gate, burning forests, wooden gates that burn down, powder kegs exploding in chain reactions.
- **Physics objects**: crates, barrels, hay, carts, boulders. Pick them up (□) and throw them (R). They break, roll, float and drift down the river.
- **Trees**: sway in the wind, can be felled by sword or explosions, crush whatever is underneath, and burn.
- **Weather and day/night**: rain, thunderstorms with lightning, fog, nights lit by fires.
- **Life**: crows circling over the battlefield that scatter at explosions, waving grass, screams, music that intensifies during assaults.
- **9 eras**: medieval, late Middle Ages, Renaissance, Baroque, industrial, Great War, Cold War, modern, contemporary. Each has its own weapons, enemies, uniforms and siege engines (rams, catapults, trebuchets, cannons, artillery, tanks, planes, helicopters, drones, missiles).
- **Allied defenders** on the wall walk, **ladders** you can push away, castle **cannons** and **machine guns**.
- **Persistence**: automatic saves. Time stops while the Vita is asleep. When the keep falls, a new era begins and the old one goes into the *Chronicles*.
- **Time acceleration** (SELECT): x1 to x64 for years, breaks between waves and the day/night cycle.

## Controls

| Button | Action |
| --- | --- |
| Left / right stick | Move / look |
| R | Fire, strike, throw held object |
| L | Aim |
| ✕ | Jump |
| △ | Switch weapon |
| □ | Pick up, use cannon or cauldron, push a ladder away |
| ○ (hold) | Repair walls |
| Up | Grenade (modern eras) |
| SELECT | Time speed |
| START | Menu (save, chronicles, controls) |

## Installation

1. You need a hacked Vita (HENkaku/Enso) with **VitaShell**.
2. The game uses vitaGL, which needs the shader compiler `ur0:data/libshacccg.suprx`. If it is missing, extract it with **ShaRKBR33D** (available in Vita Homebrew Browser).
3. Download `EternalSiege.vpk` from the repository's *Releases* and copy it to the Vita (FTP or USB with VitaShell).
4. Install the VPK from VitaShell, then launch "Eternal Siege" from the home screen.

Saves and the log (`log.txt`) are in `ux0:data/EternalSiege/`. If something goes wrong, the log shows how far startup got.

## Building

Nothing to install on your PC: on every push, **GitHub Actions** builds the game (VitaSDK + vitaGL), downloads CC0 photo textures from [Poly Haven](https://polyhaven.com) and publishes the `.vpk`.

To build locally (optional):

```bash
export VITASDK=/usr/local/vitasdk
python3 tools/fetch_textures.py build_tex   # optional: photo textures
cmake -S . -B build && cmake --build build
```

## Code layout

| File | Role |
| --- | --- |
| `src/gfx.cpp`, `textures.cpp` | vitaGL rendering, geometry batches, lights, textures, font |
| `src/terrain.cpp` | Terrain, river, grass, craters |
| `src/castle.cpp` | Block castle: meshing, damage, collapses, repair, fires |
| `src/nature.cpp`, `sky.cpp` | Trees, birds, sky, weather, rain |
| `src/bodies.cpp` | Object physics (crates, barrels, debris, ladders…) |
| `src/characters.cpp` | Articulated soldiers, animation, AI, flow field |
| `src/combat.cpp` | Projectiles, gunfire, siege engines, vehicles, fixed stations |
| `src/player.cpp` | First-person player and weapon view |
| `src/fx.cpp` | Particles, blood, scorch marks, explosions |
| `src/audio.cpp` | Synthesized sounds, 3D mixing, procedural music |
| `src/game.cpp` | Eras, waves, saving, UI |
